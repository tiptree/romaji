# ローマ字学習アプリ

## ファイル構成
- `index.html` : 画面
- `style.css` : スマートフォン向けデザイン
- `script.js` : 出題・選択肢・正誤判定
- `seion.csv` : レベル1 清音
- `dakuon_handakuon.csv` : レベル2 濁音・半濁音
- `youon.csv` : レベル3 拗音

## GitHub Pagesで公開する方法
1. GitHubで新しいリポジトリを作ります。
2. 上記6ファイルをリポジトリの一番上（ルート）にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチと `/(root)` を指定して保存します。
5. 表示されたURLをスマートフォンで開きます。

CSVを `fetch()` で読み込むため、HTMLファイルをパソコン上で直接開くのではなく、GitHub PagesなどのWebサーバー経由で開いてください。

## 出題ルール
- 選択したレベルのCSVから、kanaをランダムに出題します。
- shiinがある文字は、子音を3択で出題します。
- 子音が正解すると、boinを3択で出題します。
- shiinが空欄の「あ・い・う・え・お」などは、母音から出題します。
- 不正解は赤色で表示し、もう一度選べます。
- 母音まで正解すると、次の問題へ進めます。

## CSVデータの注意
CSVの `shiin` / `boin` は、ローマ字の正解判定に使います。誤記があるとそのまま正解として扱われるため、CSVの値を確認してください。
